# Jev 飞书助手 · macOS 安装

支持 Apple Silicon（M1/M2/M3/M4 等）、macOS 13 或更新版本。Intel Mac 尚未提供安装包。

1. 退出旧版 Jev。打开 DMG，将「Jev 飞书助手.app」拖入 Applications；已有版本时替换。
2. 从 Applications 启动。包已内置 Python，无需安装 Python、uv 或 Rust。
3. 飞书 Mac 客户端需已登录；另行安装并授权官方 lark-cli：https://github.com/larksuite/cli 。可见消息模式还需要用户身份的消息搜索权限。
4. 默认回复服务需要本机 Ollama 和 qwen3.5:4b；也可在 Jev 设置中配置其他模型或兼容服务。模型、账号和密钥不包含在安装包内。
5. 在系统「隐私与安全性」中为 Applications 中的 Jev 授予辅助功能权限（新系统可能称为「设备控制与数据访问」）。无需屏幕录制权限。
6. 打开飞书聊天，选择「跟随最新消息」或「跟随可见消息」，点击「开始跟随」。应用启动默认暂停。

本预发布包使用临时签名，尚未取得 Developer ID 签名及 Apple 公证。macOS 可能阻止首次启动。请核对下载来源与发布页 SHA-256；若系统允许，可在「隐私与安全性」中针对该应用选择「仍要打开」。无需关闭系统整体安全保护。更新后系统可能要求重新确认辅助功能授权。

「跟随可见消息」直接以屏幕最后一个对方可见气泡为准，不依赖 API 搜索，不要求它是会话最新消息。底部半截气泡也作为目标，辅助功能可能提供完整正文。支持带引用标题或表情回应的普通文字；末尾本人消息会回溯最近对方消息；最近对方消息无法提取正文时停读。目标原文在生成前显示，上下文最多取上方八条可见文字。切回「跟随最新消息」可恢复原有行为。模式选择仅在本次运行有效。

云端 Jev 判断默认开启；若只希望本地处理，请先在设置中关闭 Jev，并保留本机 Ollama。选用远端回复服务时，目标文本与最多八条此前上下文会发送至所配置服务。应用没有自动发送功能。

版本、更新记录与问题反馈：https://github.com/ai-freer/jev-feishu/releases

上下文规则：判断和回复均使用合计最多 8 条上下文消息（含目标之后的本人消息），保留发言者与时间顺序。前文及其引用合计最多 8,000 字符，每条正文最多 2,000 字符；目标正文最多 8,000 字符、目标引用最多 2,000 字符，截断显式标记。可见模式仅用屏幕上可读取的内容，不自动补取不可见历史；API 模式用稳定匿名参与者标签区分发送者。引用不等同于当前发言。

0.2.2：末尾本人消息不再直接停读，回溯最近对方消息并显示“你已回复”。后续本人消息按从旧到新单列，优先保留最近 8 条、每条最多 1,000 字符，与此前消息共用 8 条及 8,000 字符预算。候选生成后，开启 Jev 时会额外发送结构化上下文及六条候选至同一 Jev 服务，获取相对推荐度；关闭 Jev 不评分。分数不是事实正确率，失败显示未评分；评分不会覆盖用户编辑。
